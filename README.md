# CampusSpot – Smart Campus Space Finder

**Find the right space on campus, at the right time.**

CampusSpot is a smart campus space discovery platform designed to help students and campus users find available rooms and study spaces more easily. It uses timetable data and Data Structures and Algorithms (DSA) to process room availability and present useful information through an interactive web interface.

## 🎯 Problem Statement

Finding an available classroom, laboratory, or study space on a college campus can be difficult, especially when room schedules are scattered across different sources.

CampusSpot aims to simplify this process by organizing campus room and timetable information into one accessible platform.

## ✨ Key Features

- **Find Space:** Explore campus spaces and discover room availability.
- **Room Details:** View information about individual rooms.
- **Timetable Integration:** Work with structured timetable data to determine room occupancy.
- **DSA Processing:** Use C-based logic to process availability-related data.
- **Interactive Dashboard:** Access campus information through a user-friendly interface.
- **Data Import:** Support structured campus data for managing room and timetable information.
- **Admin Dashboard:** Provide an interface for administrative data management.

## 🚀 Getting Started

### Prerequisites

- Node.js and npm
- Git
- A C compiler (GCC recommended)

### Installation

1. Clone the repository:

```bash
git clone https://github.com/SANIKAKALE24/CampusSpot.git
```

2. Navigate to the project directory:

```bash
cd CampusSpot/CampusSpot\ DS\ CP
```

3. Install dependencies:

```bash
npm install
```

4. Start the frontend development server:

```bash
npm run dev
```

5. Open the local URL displayed in your terminal.
